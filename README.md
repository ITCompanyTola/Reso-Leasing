# Новогодняя вечеринка РЕСО-Лизинг — Вечер кинопремьер

Лендинг-приглашение на корпоративную костюмированную вечеринку 23.12.2026.
Одна адаптивная страница: десктопная раскладка от 1024 px, ниже — мобильная.

## Структура

```
index.html                 разметка страницы (шаблон внутри <template id="tpl">)
assets/css/style.css       стили, @font-face, анимации (сцена, софиты, неон, блёстки, пасхалки)
assets/js/app.js           логика: таймер, форма регистрации, пасхалки, эффекты при прокрутке, расчёт сцены
assets/js/runtime.js       мини-рантайм шаблона: {{…}}, <sc-if>, <sc-for>, data-dc-on*
assets/js/morphdom.min.js  morphdom (MIT) — точечно обновляет DOM, не сбрасывая поля и анимации
assets/fonts/              Cormorant Garamond, Marck Script (woff2, SIL OFL 1.1), кириллица + латиница
assets/img/                изображения (WebP / SVG), favicon, og-image
source/                    исходники из редактора Claude Design (.dc.html), для справки
```

Сборки и зависимостей нет — это статический сайт.

## Запуск локально

```
python3 -m http.server 8000
```

Откройте http://localhost:8000. Открывать `index.html` двойным кликом тоже можно, но шрифты и часть браузеров надёжнее работают через локальный сервер.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него **содержимое** этой папки (вместе со скрытыми `.nojekyll`, `.gitignore`, `.editorconfig`), чтобы `index.html` лежал в корне репозитория:
   ```
   git init
   git add .
   git commit -m "Лендинг: новогодняя вечеринка РЕСО-Лизинг"
   git branch -M main
   git remote add origin https://github.com/<аккаунт>/<репозиторий>.git
   git push -u origin main
   ```
   При загрузке через веб-интерфейс GitHub («Add file → Upload files») перетаскивайте файлы и папки изнутри `reso-leasing-party`, а не саму папку.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт будет доступен по адресу `https://<аккаунт>.github.io/<репозиторий>/`. Все пути относительные, поэтому работа из подпапки поддерживается.

## Перед запуском

- **Отправка формы.** `sendRegistration(data)` в `assets/js/app.js` — заглушка, имитирует успешную отправку. Подключите свой эндпоинт (Google Sheets / Telegram / CRM), пример — в комментарии над методом. Поля: `fullName` (фамилия и имя), `department`, `createdAt`.
- **Согласие на обработку персональных данных.** Форма собирает фамилию и имя, поэтому по 152-ФЗ нужны чекбокс согласия и ссылка на политику. Сейчас их на странице нет.
- **og:image** указан относительным путём; для корректного превью в мессенджерах замените на абсолютный URL после публикации.
- **Дата отсчёта таймера** — в `renderVals()`: `Date.UTC(2026, 11, 23, 14, 0, 0)` (23.12.2026, 17:00 МСК). Регистрация — до 10.12.

## Пасхалки

- Клик по снежинке-печати — снегопад и поздравление.
- Клик по неоновой вывеске «Премьера» — искры, вывеска гаснет и загорается «С Новым годом!».
- Клик по дверям кинотеатра — двери открываются, золотое конфетти и звонок.
- Клик по карточкам образов: Индиана Джонс — катящийся валун; Марти Макфлай — молния и «Вернулся из 1985!»; Дороти — блёстки и надпись; Мэри Поппинс — карточка взлетает.

## Производительность

- Изображения в WebP, ниже первого экрана — `loading="lazy"`; сцена главного экрана и основные шрифты — `preload`.
- Шрифты свои, без запросов к сторонним сервисам; `font-display: swap`, загружаются только нужные начертания и алфавиты.
- Анимации работают всегда, в том числе при системной настройке «уменьшить движение».
