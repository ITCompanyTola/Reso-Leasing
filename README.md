# Новогодняя вечеринка РЕСО-Лизинг — Вечер кинопремьер

Лендинг-приглашение на корпоративную костюмированную вечеринку 23.12.2026.
Одна адаптивная страница: десктопная раскладка от 1024 px, ниже — мобильная.

## Структура

```
index.html                 разметка страницы (шаблон внутри <template id="tpl">)
assets/css/style.css       стили, @font-face, анимация главного экрана
assets/js/app.js           логика: таймер, форма и валидация, пасхалка, расчёт сцены
assets/js/runtime.js       мини-рантайм шаблона: {{…}}, <sc-if>, <sc-for>, data-dc-on*
assets/js/morphdom.min.js  morphdom (MIT) — точечно обновляет DOM, не сбрасывая поля и анимации
assets/fonts/              Cormorant Garamond, Marck Script (woff2, SIL OFL 1.1), кириллица + латиница
assets/img/                изображения (WebP / SVG), favicon, og-image
source/                    исходники из редактора Claude Design (.dc.html), для справки
```

Сборки и зависимостей нет — это статический сайт.

## Запуск локально

```
python3 -m http.server 8000
```

Откройте http://localhost:8000.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое этой папки (вместе со скрытыми `.nojekyll`, `.gitignore`, `.editorconfig`):
   ```
   git init
   git add .
   git commit -m "Лендинг: новогодняя вечеринка РЕСО-Лизинг"
   git branch -M main
   git remote add origin https://github.com/<аккаунт>/<репозиторий>.git
   git push -u origin main
   ```
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.

Все пути относительные, поэтому сайт работает и в подпапке `https://<аккаунт>.github.io/<репозиторий>/`.

## Перед запуском

- **Отправка формы.** `sendRegistration(data)` в `assets/js/app.js` — заглушка, имитирует успешную отправку. Подключите свой эндпоинт (Google Sheets / Telegram / CRM), пример — в комментарии над методом. Поля: `fullName`, `film`, `hero`, `consent`, `createdAt`.
- **Согласие на обработку персональных данных.** Форма собирает ФИО, поэтому по 152-ФЗ нужны чекбокс согласия и ссылка на политику. Сейчас их на странице нет.
- **og:image** указан относительным путём; для корректного превью в мессенджерах замените на абсолютный URL после публикации.
- **Дата отсчёта таймера** — в `renderVals()`: `Date.UTC(2026, 11, 23, 14, 0, 0)` (23.12.2026, 17:00 МСК).

## Производительность

- Первая загрузка ≈ 1 МБ (из них ≈ 620 КБ — анимированная сцена главного экрана), полная страница ≈ 1,2 МБ, 43 запроса.
- Изображения ниже первого экрана — `loading="lazy"`, сцена и основные шрифты — `preload`.
- Шрифты свои, без запросов к сторонним сервисам; `font-display: swap`, загружаются только нужные начертания и алфавиты.
- Перерисовка таймера раз в секунду ≈ 3 мс.
- При `prefers-reduced-motion` анимации отключаются.
